# Чат-бот "Молодежь ВВГУ"

Telegram-бот для абитуриентов и студентов: приветствует, собирает анкету, запоминает студента и показывает направления активности университета.

## Что уже есть

- Анкета: ФИО, контактный номер, возраст, пол, интересы и направление обучения.
- Сохранение студента в SQLite: при повторном `/start` бот обращается по имени.
- Меню активностей: спорт, волонтерство, студенческие отряды и другие разделы.
- Карточки клубов/центров: описание, контакты, место/мероприятия и фото.
- Контакты объединения открываются только после кнопки `Записаться`.
- Раздел `Рекомендации` показывает 5 объединений, которые могут подойти студенту.
- Навигация назад к разделам и главному меню.
- Анкета остается в истории чата.
- После анкеты основные разделы работают через кнопки: бот редактирует экран меню, а не отправляет много новых сообщений.

## Запуск

1. Создайте основного бота через [BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Вставьте токен основного бота:

```env
TELEGRAM_BOT_TOKEN=123456:ABCDEF
```

4. Запустите:

```powershell
python main.py
```

Зависимости устанавливать не нужно: бот использует только стандартную библиотеку Python.

## Админ-бот

Админ-бот нужен, чтобы менять тексты, направления обучения, интересы анкеты, разделы, объединения, контакты и фото прямо из Telegram.

1. Создайте второго бота через BotFather.
2. Вставьте его токен в `.env`:

```env
ADMIN_BOT_TOKEN=123456:ADMIN_TOKEN
```

3. Узнайте свой Telegram ID. Для этого можно временно запустить админ-бота и отправить ему `/id`:

```powershell
python admin_main.py
```

4. Добавьте ID в `.env`:

```env
ADMIN_TELEGRAM_IDS=123456789
```

Если админов несколько, перечислите их через запятую:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
```

5. Запустите админ-бота:

```powershell
python admin_main.py
```

Можно запустить обоих ботов одной командой:

```powershell
python run_bots.py
```

Также их можно запускать отдельно в разных терминалах:

```powershell
python main.py
python admin_main.py
```

## Диагностика

Проверить токены и доступ к Telegram API:

```powershell
python check_bots.py
```

Если в логах появляется строка `slow Telegram request`, бот не завис в логике: задержка идет на стороне сети или Telegram API.

Не запускайте одновременно `python run_bots.py`, `python main.py` и `python admin_main.py`, иначе боты будут конкурировать за обновления.

## Как редактировать активности

Все разделы лежат в [content/activities.json](C:/Users/PVN-LP7/Desktop/Bot/Mo;odezhka_bot/content/activities.json).

Этот файл можно редактировать руками или через админ-бота.

Фото лучше загружать через админ-бота:

1. Откройте нужный экран: приветствие, текст бота, раздел или объединение.
2. Нажмите `Загрузить фото`.
3. Отправьте картинку одним сообщением.

Бот сам сохранит Telegram `file_id`. Чтобы убрать картинку, нажмите `Удалить фото`.

Пример:

```json
{
  "title": "Баскетбол",
  "photo": "telegram_file_id",
  "contact": "Иван Иванов, @username",
  "where": "Спортзал ВВГУ"
}
```

## Команды

- `/start` - начать или вернуться в меню.
- `/menu` - главное меню.
- `/profile` - посмотреть анкету.
- `/restart` - заново заполнить анкету.

## Как считаются рекомендации

Когда студент нажимает `Записаться`, бот сохраняет заявку на объединение. Раздел `Рекомендации` подбирает до 5 объединений по заявкам студентов с похожими параметрами: направление обучения, пол и выбранные интересы.

## Файлы данных

Анкеты студентов сохраняются в `data/bot.sqlite3`. Этот файл создается автоматически при первом запуске.
